# Litiqo — AI-Powered Legal Case Intelligence

A modern legal case management SaaS platform built with Next.js, TypeScript, and Tailwind CSS.

## Features

- **Case Management** — Create, track, and manage civil litigation cases
- **6 Intake Methods** — Form, Paste Notes, Voice Note, Upload, Email Forward, Quick Templates
- **Document Generator** — AI-powered legal document creation with step-by-step progress
- **Client Portal** — Invite clients with customizable permissions
- **Notifications** — Deadline reminders, AI suggestions, client activity alerts
- **Jurisdiction-Aware** — Adapts to UAE, UK, US, Saudi, India legal systems
- **Dark Mode** — Full light/dark theme support

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + CSS Custom Properties
- **Database:** Supabase (PostgreSQL)
- **Icons:** Lucide React
- **Deployment:** Vercel

## Deploy to Vercel

1. Push to GitHub
2. Import in Vercel
3. Add environment variables
4. Connect litiqo.com domain
